# Мобильное приложение: iOS и Android

Приложение `apps/mobile` написано на Expo (React Native). Из одного кода собираются iOS, Android и веб-версия CRM.

## Разработка на своём телефоне

1. Запустите API: `pnpm dev:api`.
2. В `apps/mobile/.env` укажите IP компьютера в локальной сети: `EXPO_PUBLIC_API_URL=http://192.168.1.10:4000/v1`.
3. Запустите `pnpm dev:mobile` и отсканируйте QR-код приложением **Expo Go**.

## Сборка для магазинов (EAS)

Сборка идёт в облаке Expo, Mac для iOS не нужен.

```bash
npm i -g eas-cli
```

```bash
cd apps/mobile && eas login
```

```bash
eas init   # привяжет проект, пропишет projectId в app.json
```

1. В `eas.json` замените `https://mioflow.ru` на свой домен.
2. В `app.json` уже стоят `bundleIdentifier` и `package` = `ru.mioflow.app`. После публикации их уже не поменять.
3. Иконки и заставка MioFlow уже лежат в `assets/` (исходники — `brand/`).

Тестовая сборка (APK для Android и internal-сборка для iOS):

```bash
eas build --profile preview --platform android
```

Сборка для публикации:

```bash
eas build --profile production --platform all
```

```bash
eas submit --platform ios
```

```bash
eas submit --platform android
```

## Аккаунты разработчика

| Магазин | Стоимость | Комментарий |
|---|---|---|
| **Google Play** | $25 один раз | Новые личные аккаунты проходят закрытое тестирование: около 12 тестировщиков в течение 14 дней. |
| **App Store** | $99 в год | Оплатить с российской карты сейчас сложно. Нужна карта другой страны или юрлицо за рубежом. |
| **RuStore** | бесплатно | Для РФ стоит публиковаться и здесь: тот же APK или AAB. |

Правила магазинов, которые относятся к нашему приложению:

- **Удаление аккаунта.** Apple требует возможность удалить аккаунт прямо в приложении. Готово: «Ещё» → «Удалить аккаунт».
- **Политика конфиденциальности.** В App Store и Google Play нужна ссылка на неё (`/privacy`).
- **Оплата подписки.** Подписку на B2B-сервис можно оплачивать вне приложения, на сайте через платёжного провайдера. Поэтому в iOS-приложении кнопки «Оплатить» нет — показывается только статус подписки (сделано в `billing.tsx`). На Android и в веб-версии оплата по ссылке работает.

## Обновления без магазина (OTA)

Исправления JS-кода можно доставлять сразу, без повторного ревью: `eas update --branch production`. Для этого сначала нужно подключить модуль `expo-updates` (`npx expo install expo-updates`) и пересобрать приложение. Изменения нативных модулей всё равно требуют новой сборки.
