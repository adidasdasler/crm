# Бренд «Пора»

**Пора** — онлайн-запись и напоминания для салонов красоты. Название взято из главной фразы продукта: «Пора к мастеру».

## Знак

Циферблат с одной стрелкой и розовой точкой, как у непрочитанного уведомления.

| Файл | Что это |
|---|---|
| `brand/mark.svg` | Знак в круге — логотип, сплэш, превью |
| `brand/app-icon.svg` | Квадратная иконка — фавикон, иконки приложения |
| `brand/render.js` | Генерирует PNG-иконки для iOS/Android/веба и картинку для соцсетей: `node brand/render.js` |

Логотип = знак + слово «пора» строчными буквами, шрифт Yeseva One.

- Знак не перекрашивать, не поворачивать, не добавлять тени.
- Минимальный размер знака — 16 px.

## Цвета

| Токен | HEX | Где |
|---|---|---|
| Ультрамарин | `#2F3BFF` | Кнопки, выбранное, знак, ссылки |
| Ультрамарин тёмный | `#1F28D6` | Нажатие, наведение |
| Пудра | `#FFC7D6` | «Свободно», выбранное время, точка-уведомление. Текст на ней — только «Ночь» |
| Ночь | `#0E0F2B` | Основной текст |
| Приглушённый | `#5A5E7E` | Второстепенный текст (контраст 6:1 на белом) |
| Иней | `#EEF0FF` / `#F3F4FF` | Подложки, выделения |
| Фон | `#F7F7FC` | Фон приложения |

Статусы записей используют свои спокойные пары «текст на фоне» (`apps/mobile/src/lib/format.ts`). Красный — только для отмены и ошибок.

## Шрифты

Оба шрифта бесплатные (OFL) и с полной кириллицей.

- **Yeseva One** — заголовки, крупные даты, название салона. Одно начертание, не делать жирным.
- **Golos Text** — весь остальной текст: 400, 500, 600, 700.

В приложении шрифты подключены через `@expo-google-fonts`, начертание выбирает компонент `src/components/Text.tsx`. На сайте — через Google Fonts и `font-display` в Tailwind.

## Форма

- Кнопки и чипы — «таблетки» (полностью скруглённые).
- Карточки — скругление 20–24 px, тонкая рамка вместо тени.
- Тень только у плавающей кнопки «+», с оттенком ультрамарина.

## Голос

Коротко, по-человечески, на «вы», без канцелярита и восклицаний.

| Можно | Нельзя |
|---|---|
| «Пора к мастеру: завтра в 14:00» | «Уведомляем вас о запланированном визите» |
| «Окно освободилось — записать?» | «Слот доступен для бронирования!!!» |

## Перед запуском

Проверить свободу домена (`pora.app`, `porakmasteru.ru`, …) и товарного знака «Пора» в ФИПС (классы 9, 35, 42). Если имя занято, используйте вариант «Пора к мастеру».
