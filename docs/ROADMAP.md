# План работ

## ✅ Этап 1 — ядро (готово)

- API: салоны, роли, мастера и графики, услуги, клиенты, записи, слоты, онлайн-запись, RLS, тесты.
- Сайт: лендинг, страница записи, «управлять записью».
- Приложение: iOS, Android и веб CRM. Календарь, записи, клиенты, услуги, мастера, команда, настройки.
- Деплой: Docker Compose, Nginx, скрипты деплоя и бэкапов, CI.

## Этап 2 — то, за что салоны платят (следующее)

1. **Напоминания** — главная ценность продукта.
   - Воркер на BullMQ читает таблицу `Reminder`; она уже заполняется при создании записи.
   - Telegram-бот: клиент после записи жмёт «Получать напоминания» (deep link `t.me/<бот>?start=<token>`), бот запоминает `chatId`. Напоминание приходит с кнопками «Подтвердить» и «Отменить».
   - Резервный канал — SMS (SMS.ru или аналог) для клиентов без Telegram. Пакеты SMS включены в тариф (`Plan.limits.smsPerMonth`).
2. **Оплата подписки через ЮKassa.**
   - Рекуррентные платежи (`save_payment_method`) и чеки по 54-ФЗ («Чеки от ЮKassa»).
   - Webhook проверяется по IP и повторным запросом статуса платежа через API ЮKassa.
   - Cron переводит подписку в `PAST_DUE`, а затем в `EXPIRED`. При `EXPIRED` онлайн-запись отключается (проверка уже есть).
3. **Push-уведомления** в приложении о новой онлайн-записи (expo-notifications).
4. **Восстановление пароля по email**, приглашения сотрудников письмом, удаление аккаунта в приложении (требование Apple).
5. **Sentry**, капча (Yandex SmartCaptcha) на онлайн-записи.

## Этап 3 — удержание и рост

- Импорт из YCLIENTS и DIKIDI (CSV): API импорта клиентов уже есть.
- Повторная запись в один клик, «напомнить через N недель» (возврат клиентов).
- Отчёты: выручка, загрузка мастеров, источники записей.
- Отзывы после визита (`AFTER_VISIT`).
- Расчёт зарплаты мастеров, склад, филиалы.
