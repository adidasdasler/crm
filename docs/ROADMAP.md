# План работ

## ✅ Этап 1 — ядро (готово)

- API: салоны, роли, мастера и графики, услуги, клиенты, записи, слоты, онлайн-запись, RLS, тесты.
- Сайт: лендинг, страница записи, «управлять записью».
- Приложение: iOS, Android и веб CRM. Календарь, записи, клиенты, услуги, мастера, команда, настройки.
- Деплой: Docker Compose, Nginx, скрипты деплоя и бэкапов, CI.

## Этап 2 — то, за что салоны платят (следующее)

1. **Напоминания** — главная ценность продукта.
   - Воркер на BullMQ читает таблицу `Reminder`; она уже заполняется при создании записи.
   - Telegram-бот: клиент после записи жмёт «Получать напоминания» (deep link `t.me/<бот>?start=<token>`), бот запоминает `chatId`. Напоминание приходит с кнопками «Подтвердить» и «Отменить».
   - Резервный канал — SMS (SMS.ru или аналог) для клиентов без Telegram. Пакеты SMS включены в тариф (`Plan.limits.smsPerMonth`).
2. **Оплата подписки (вы — самозанятый, НПД).**
   - Провайдер, который работает с самозанятыми и сам регистрирует чек в «Мой налог»: ЮKassa (тариф для самозанятых), Robokassa и др. **До разработки уточните у провайдера, доступны ли самозанятому автоплатежи (рекурренты)**: от этого зависит, будет ли автопродление или ежемесячная оплата по ссылке.
   - Онлайн-касса и 54-ФЗ не нужны: их заменяет чек из «Мой налог». Для салонов-ИП/ООО в чеке должен быть их ИНН, иначе им неудобно учитывать расход.
   - Webhook проверяется по IP и повторным запросом статуса платежа у провайдера. Cron переводит подписку в `PAST_DUE`, а затем в `EXPIRED`; при `EXPIRED` онлайн-запись отключается (проверка уже есть).
3. **Push-уведомления** в приложении о новой онлайн-записи (expo-notifications).
4. **Восстановление пароля по email**, приглашения сотрудников письмом, удаление аккаунта в приложении (требование Apple).
5. **Sentry**, капча (Yandex SmartCaptcha) на онлайн-записи.

## Этап 3 — удержание и рост

- Импорт из YCLIENTS и DIKIDI (CSV): API импорта клиентов уже есть.
- Повторная запись в один клик, «напомнить через N недель» (возврат клиентов).
- Отчёты: выручка, загрузка мастеров, источники записей.
- Отзывы после визита (`AFTER_VISIT`).
- Расчёт зарплаты мастеров, склад, филиалы.

## Чек-лист запуска (не код)

Вы работаете как **самозанятый (НПД)**. Для старта этого достаточно.

- [ ] Подключить приём платежей для самозанятых (ЮKassa/Robokassa) с автоматической передачей чеков в «Мой налог».
- [ ] Налог: 4% с оплат от физлиц, 6% с оплат от ИП и ООО. Большинство салонов — ИП, значит в основном 6%.
- [ ] **Лимит дохода НПД — 2,4 млн ₽ в год.** Это примерно 100 салонов на тарифе «Бизнес». Когда подойдёте к 70–80% лимита, откройте ИП: на НПД нельзя превышать лимит и нельзя нанимать сотрудников по трудовому договору.
- [ ] Юрист: оферта от самозанятого с поручением на обработку ПДн (салон — оператор данных своих клиентов, вы — обработчик), политика ПДн, отдельное согласие. Тексты заменяют заглушки в `apps/web/src/pages/Legal.tsx`.
- [ ] Уведомление Роскомнадзору об обработке ПДн: уточните у юриста, нужно ли оно в вашем случае (как правило, нужно).
- [ ] Домен и VPS в РФ, деплой по [DEPLOY.md](DEPLOY.md).
- [ ] Telegram-бот через @BotFather.
- [ ] Аккаунты Google Play, App Store и RuStore на физлицо ([MOBILE.md](MOBILE.md)).
- [ ] **5–10 салонов на бесплатный пилот** за обратную связь. Это важнее любой новой функции.
- [ ] Проверить цены тарифов на пилоте. Сейчас в `prisma/seed.ts` стоит гипотеза: 990, 1990 и 3990 ₽/мес.
