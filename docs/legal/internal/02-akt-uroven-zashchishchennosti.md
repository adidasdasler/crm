# Акт определения уровня защищённости персональных данных в ИСПДн «MioFlow»

г. Москва · «___» __________ 20__ г.

Составлен по постановлению Правительства РФ от 01.11.2012 № 1119.

## 1. Исходные данные

| Показатель | Значение |
|---|---|
| Информационная система | MioFlow: онлайн-запись и учёт клиентов (mioflow.ru, app.mioflow.ru) |
| Категории ПДн | Иные (ФИО, телефон, email, сведения о записях на услуги, идентификаторы в мессенджерах). Специальные категории и биометрия **не обрабатываются** |
| Чьи данные | Не сотрудники оператора: пользователи сервиса и клиенты салонов (по поручению салонов) |
| Количество субъектов | Менее 100 000 |
| Тип актуальных угроз | 3-й тип: угрозы, не связанные с недекларированными возможностями в системном и прикладном ПО |

## 2. Вывод

Для ИСПДн «MioFlow» установлен **4-й уровень защищённости (УЗ-4)**.
При превышении 100 000 субъектов уровень пересматривается (УЗ-3).

## 3. Краткая модель угроз и принятые меры

| Угроза | Меры |
|---|---|
| Перехват данных при передаче | HTTPS (TLS 1.2+), HSTS |
| Подбор или кража пароля пользователя | Хэши argon2id, блокировка после неверных попыток, ограничение частоты запросов, отзыв сессий |
| Доступ одного салона к данным другого | Изоляция на уровне СУБД (Row Level Security), автотесты изоляции |
| Избыточный доступ сотрудника салона | Роли и настраиваемые права, скрытие телефонов, журнал действий |
| Взлом сервера через уязвимость ПО | Контейнеры без привилегий, база без выхода в интернет, обновления, проверка зависимостей |
| Потеря данных | Ежедневные зашифрованные (AES-256) резервные копии, проверка восстановления |
| Утечка через резервные копии | Шифрование копий, пароль хранится отдельно |
| Внедрение вредоносного кода на сайт (XSS, подмена запросов) | Content-Security-Policy, httpOnly-cookie, защита от CSRF |
| Передача данных за рубеж без оснований | Сервер в РФ; Telegram и push включаются только после уведомления Роскомнадзора |

Средства криптографической защиты, сертифицированные ФСБ, для УЗ-4 при данной модели угроз не применяются.
