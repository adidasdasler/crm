# MioFlow — онлайн-запись и CRM для салонов красоты

SaaS для салонов на 1–10 мастеров: онлайн-запись для клиентов, календарь, база клиентов, мастера и графики, команда с ролями. Есть приложение для iOS и Android и веб-версия CRM.

## Из чего состоит

| Часть | Папка | Технологии | Где работает |
|---|---|---|---|
| **API** | `apps/api` | NestJS 11, Prisma 6, PostgreSQL 16 (RLS) | `mioflow.ru/v1` |
| **Сайт + онлайн-запись** | `apps/web` | React 19, Vite, Tailwind | `mioflow.ru`, `mioflow.ru/b/<салон>` |
| **Приложение CRM** | `apps/mobile` | Expo SDK 58 (React Native) | iOS, Android, веб `app.mioflow.ru` |
| **Деплой** | `deploy/`, `docker-compose.yml` | Docker, Nginx | VPS |

Одна кодовая база `apps/mobile` собирается в три платформы: iOS, Android и веб.

## Что уже работает

- Регистрация салона: 14 дней пробного периода, согласие на обработку ПДн.
- Роли OWNER, MANAGER, ADMIN, MASTER. Мастер видит только свои записи.
- Мастера с недельным графиком, услуги с категориями, шаблоны (маникюр, парикмахерская, брови, барбершоп).
- Клиенты: поиск, история визитов, заметки, метки, согласие на рассылки, импорт, обезличивание при удалении.
- Записи:
  - несколько услуг в одном визите;
  - технический перерыв после услуги;
  - «любой мастер»;
  - запись вне графика для сотрудников;
  - статусы с проверкой переходов;
  - optimistic locking.
- **Двойная запись невозможна:** её запрещает ограничение `EXCLUDE` в PostgreSQL. Тест: из 10 одновременных запросов проходит ровно один.
- Онлайн-запись для клиентов: услуги → мастер → время → контакты. Клиент получает ссылку «управлять записью», по которой можно подтвердить или отменить визит.
- **Напоминания клиентам** за 24 и за 2 часа: в Telegram, MAX или ВКонтакте с кнопками «Подтвердить» и «Отменить», иначе — на email. Без платных SMS.
- **Кабинет владельца:** выручка, средний чек, загрузка мастеров, неявки, источники клиентов. На компьютере — веб-версия с боковым меню.
- **Роли и доступы:** владелец настраивает права управляющего, администратора и мастера (все записи, база клиентов, телефоны, отчёты, услуги, команда).
- **Мини-сайт и карты:** страница салона с услугами, часами и адресом, разметка schema.org для поисковиков, ссылки с метками и QR для Яндекс Карт, 2ГИС, VK.
- **Склад материалов:** приход партиями со сроком годности, автосписание по нормам расхода при завершении визита (сначала партии, которые истекают раньше), списание, инвентаризация, предупреждения «заканчивается» и «истекает срок», готовые наборы материалов для сфер, расход материалов в отчёте.
- **Оценки после визита:** через 2 часа клиенту приходит «Как прошёл визит? 1–5⭐» (Telegram, MAX, ВКонтакте или письмо со ссылкой). Довольных просим оставить отзыв на Яндекс Картах и 2ГИС, о недовольных владелец узнаёт сразу — с телефоном клиента и комментарием.
- **Советы владельцу:** пустые окна по времени суток, клиенты, которые давно не приходили, перегруз мастеров и повод поднять цену, неявки, доля онлайн-записей, склад. В «Обзоре» и в еженедельной сводке в понедельник утром.
- **Депозиты и абонементы:** пополнение с бонусом по ступеням («внесите 5 000 — получите 5 500»), абонементы на N визитов или безлимит, на выбранные услуги и непиковые часы. При завершении визита сначала списывается подходящий абонемент, иначе — депозит. Возврат денег (бонусы сгорают пропорционально). Витрина на мини-сайте, баланс клиента — по его личной ссылке. MioFlow ведёт только учёт: деньги принимает салон.
- **Разные сферы:** красота, фитнес, репетиторы, груминг, автосервисы и др. — слова интерфейса и стартовые услуги под сферу.
- **Telegram-уведомления сотрудникам** о новых онлайн-записях, отменах и оплате.
- **Подписка:** 14 дней бесплатно, затем оплата по ссылке за месяц или год (ЮKassa, чек в «Мой налог»). Тарифы 290 / 690 / 1490 / 2990 ₽ отличаются только числом мастеров.
- **Аккаунт:** восстановление пароля по email, удаление аккаунта в приложении, выгрузка клиентов в Excel, push-уведомления о новых записях.
- **Юридические черновики:** оферта, политика ПДн, отдельные согласия — см. [docs/legal](docs/legal/README.md).
- Изоляция салонов на уровне БД (Row Level Security). Тесты проверяют, что салон B не видит данных салона A.
- Безопасность:
  - argon2id;
  - JWT 15 минут + ротация refresh-токенов с обнаружением кражи;
  - блокировка после 5 неудачных попыток входа;
  - rate limit;
  - CSRF-защита;
  - аудит-лог.

Что дальше: [docs/ROADMAP.md](docs/ROADMAP.md).

## Быстрый старт (разработка)

Нужны Node.js 22+, pnpm 10+, PostgreSQL 16.

```bash
pnpm install
```

```bash
# БД: владелец схемы salon / роль приложения salon_app (создаётся миграцией)
createuser -s salon && createdb -O salon salon
```

```bash
cp apps/api/.env.example apps/api/.env
cd apps/api && npx prisma migrate deploy && pnpm prisma:seed
```

```bash
psql -d salon -c "ALTER ROLE salon_app LOGIN PASSWORD 'salon_app';"
```

Запуск, каждая команда в отдельном терминале:

```bash
pnpm dev:api      # http://localhost:4000/v1
```

```bash
pnpm --filter @salon/api dev:worker   # напоминания и проверка подписок
```

```bash
pnpm dev:web      # http://localhost:5173 и http://localhost:5173/b/demo
```

```bash
pnpm dev:mobile   # Expo: w — веб, QR-код — Expo Go на телефоне
```

Демо-вход: `demo@salon.local` / `demo12345`.

Тесты API (нужна отдельная БД `salon_test` с применёнными миграциями):

```bash
pnpm --filter @salon/api test
```
